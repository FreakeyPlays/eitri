# User Guide

Eitri is in early development. For setup and launch instructions, see the
[README](../../README.md#installation).

## What works today

Eitri opens its application layout: a sidebar, the main area, a right panel,
and a terminal area. Projects, chats, and sending prompts to an agent are not
available yet. **New Chat**, **Add Project**, and **Settings** are placeholders,
and the right panel and terminal are empty.

- **Panels:** show or hide the sidebar, terminal, and right panel with the
  buttons in the application bar. Drag the handle between two panels to resize
  them, or focus the handle and use the arrow keys. Eitri remembers panel sizes
  and visibility.
- **Command palette:** press ⌘K or Ctrl+K to navigate or toggle a panel by name.
